# 产品说明（PRODUCT）

## 1. 定位

LiveMemory（直播记忆）是给普通主播使用的 **Windows 本地软件**：记录直播、沉淀场次数据、建立长期观众记忆，并通过手动文件往返或一键自动分析使用 AI 服务做内容分析。

不是开发者实验平台，不依赖云服务，不替代主播做经营或人际判断。

## 2. 必须坚持的原则

1. 本地优先：数据只保存在用户电脑。
2. 免费使用。
3. 不要求用户申请 AI API Key 或注册账号；自动模式使用已验证的匿名免费接口，失败可回退手动。
4. 开发者不需要维护云端服务器。
5. AI 分析默认通过手动文件往返；自动模式是可选入口，不改变手动流程。
6. 长期观众记忆增量更新。
7. 完整数据导出、导入与跨电脑迁移（M5 起）。
8. 默认尽量减少长期原始弹幕存储（精简模式）。
9. Windows 普通用户无需开发知识即可使用。
10. UI、启动器、错误提示支持中文、日语、英语。
11. 每轮开发同步文档、测试与 Git 状态。
12. 文本优先：普通 Emoji 原样保存；平台表情优先保留文字名称/代码，不强制还原图片，不猜测未知表情含义。

## 3. 第一版范围

### 3.1 按直播查看

- 平台、开始时间、时长、直播标题
- 消息总数、独立观众数
- 各时间段消息密度与热度变化（自动粒度）
- 峰值速度
- 礼物 / SC / 大航海 / 会员等经济支持事件与按币种精确累计
- AI 导入后的主题、情绪、争论、回看与切片建议（M6）

### 3.2 按观众查看

- 平台 + 稳定用户 ID（`platform:uid`）
- 当前昵称与昵称历史
- 首次 / 最近出现时间
- 累计场次、累计发言
- 送礼次数与按币种累计支持（区分实际支付 / 展示价值）
- 长期兴趣、明确喜恶、关注变化（AI，M7）
- 主播手动「重点关注」标记（已实现基础开关）

观众页默认展示摘要与统计，不展示数千条原始聊天。

### 3.3 页面

一级导航：直播记录、直播历史、观众档案、AI 分析中心、设置。

### 3.4 AI 文件往返

分析包（`livememory-analysis-v1`）包含：

```text
manifest.json          协议版本、任务 ID、场次、计数、文件校验和
session_context.json   场次元数据、本地统计、时间线、表情字典
messages.jsonl         逐行 JSON，seq 有序，content 为不可信文本，可含 content_ai/emote_refs
viewer_context.json    观众身份与长期累计
instructions.md        按界面语言生成的任务说明（含 Emoji/平台表情规则）
result.schema.json     结果 JSON Schema
```

普通 Unicode Emoji 直接保留；平台表情优先保留文字名称/代码，不强制下载图片。M6 已实现导出、分批、汇总、导入与严格 Schema 校验，并把结果展示为直播分析报告。

## 4. 非目标

- 不做云同步、账号体系、遥测。
- 不做自动经营建议、消费诱导或敏感属性推断。
- 不承诺 AI 对视频/语音内容的理解：本地只记录平台事件。
- 不在第一版做两台电脑数据自动合并（只做完整恢复）。

## 6. 用户日常流程

打开 EXE → 自动打开浏览器 → 开始记录 → 结束直播 → 创建分析任务并导出分批分析包 → 交给任意 AI 服务 → 导入 JSON 结果 → 查看直播分析报告（必要时生成/导入第二阶段汇总）。

更换电脑：旧电脑导出全部数据 → 新电脑导入备份 → 恢复历史、画像、统计和设置 → 必要时重新登录平台。
