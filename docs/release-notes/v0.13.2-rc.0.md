# LiveMemory v0.13.2 RC0

> **预发布版本（Pre-release）** · Windows 10/11 x64 · 本地优先
>
> Build ID：`e438e74803cb` · SHA-256：`0cf672438a4723589f4164316e98965a6ff549a132deb30a243638a3f62531c8`

LiveMemory 是一款运行在你自己 Windows 电脑上的直播记录与观众记忆工具。它可以记录 **Bilibili Live** 与 **YouTube Live** 的聊天、礼物、醒目留言和会员事件，按场次统计，并借助你自己配置的 AI 模型完成单场分析与长期观众画像。

它不需要你部署服务器，不需要安装 Python、Node.js 或数据库；下载 `LiveMemory.exe` 双击即可使用。所有直播数据、观众资料、AI 分析结果与长期记忆都保存在你的电脑上，AI 请求由本地程序直接发送给你选择的 Provider。

## 主要功能

### 直播记录与观众资料

- 支持 Bilibili Live 与 YouTube Live，可同时记录多场直播，每场有独立标签、连接状态与停止操作。
- 记录聊天、礼物、Super Chat、会员事件与平台表情；金额按币种和「实际支付 / 展示价值」分别统计，不混加。
- 观众以平台稳定 ID 识别；同名但不同平台或不同 ID 的观众不会被合并。
- 直播历史支持按主播、标题、观众搜索，并按平台、状态、日期和归档筛选。
- 观众档案包含互动历史、支持记录、昵称历史与跨场次长期记忆。

### 用你自己的 AI Provider 做分析

- 仅使用你自行配置的 API Key，不经过开发者服务器，也没有匿名免费 AI。
- 支持 OpenAI、Anthropic、DeepSeek、MiniMax、阿里云百炼（多个区域）、OpenRouter 以及自定义 OpenAI-compatible 服务。
- 一次任务可以同时生成「本场报告」和「长期观众画像」，两者独立保存；画像失败不会删除已完成的单场报告。
- API Key 保存在本机加密凭据库中，不进入配置 JSON、日志、备份或界面源码。

### 长期观众记忆

- 为每位「主播 × 观众」维护一份长期记忆，包含事实、可信度、状态变化与原始证据。
- 支持「观众明确说过 / AI 推断 / 无法确认」的区分；状态变化保留历史，不静默覆盖。
- 每条事实都可以展开对应场次与消息；原文被保留策略清理后，会明确标记证据不可用。
- 可查看历史版本、回滚、确认/忽略/删除单条事实，或删除整位观众的长期记忆。
- 程序会拒绝无证据的「明确说过」、跨观众证据与非法身份；但**引用合法不等于语义一定正确**，请结合证据判断。

### 进度、失败恢复与费用

- 实时显示分析阶段、批次/观众进度、请求数、Token 用量与估算费用。
- 批次成功即保存；失败会保留已完成部分，并提供「继续」入口，只重试未完成或失败的批次与观众。
- 关闭程序或重启电脑后仍可继续；已完成任务再次继续不会产生新的 Provider 请求。
- 显示 Provider 返回的输入/输出/缓存/推理 Token，以及按你填写的单价计算的**估算费用**。

### 本地备份、恢复与迁移

- 一键创建单个 `.livememory` 备份文件，包含场次、聊天、观众、支付、长期画像、AI 报告与设置。
- 备份不包含 API Key、Bilibili 登录凭据、日志、缓存或运行状态。
- 可在本机或另一台 Windows 电脑恢复；恢复前自动保存当前数据，失败可回滚。
- 备份文件未加密，包含观众昵称、聊天与 AI 报告，请妥善保管。

### 三语界面与内置使用说明

- 简体中文 / 日本語 / English 三语界面，可跟随系统或手动切换，并记住选择。
- 内置「使用说明」页面，按实际操作顺序介绍首次启动、平台连接、记录与历史、AI 配置、分析、长期记忆、失败恢复、备份迁移与常见问题。
- 支持明亮 / 黑暗 / 跟随系统主题，桌面与窄屏布局。

## RC0 的主要改进

RC0 的重点是稳定性、安全性与可靠性，而不是新增更多入口：

- **启动更可靠**：正式 EXE 在启动时自动向 Windows 申请管理员权限，解决部分电脑上因数据目录不可写导致的 `Bootstrap` 启动失败。
- **本地 API 会话认证**：除健康检查和会话交换外，所有本地 API（含实时事件流）都需要启动器建立的随机会话凭据；伪造来源、跨站请求和恶意 Host 会被拒绝。
- **凭据保护**：API Key 只保存在本机加密凭据库；备份和导出不包含凭据。
- **数据完整性**：SQLite 一致快照、恢复日志与崩溃回滚、备份格式与校验和验证，避免直接复制正在写入的数据库。
- **AI 恢复能力**：批次级保存、有界重试、截断/空响应处理、观众级失败隔离与断点继续，避免一个失败拖垮整场分析。
- **长期画像校验**：事实必须通过 Schema、身份、证据与覆盖校验；无证据的「明确说过」与跨观众证据会被拒绝。
- **YouTube 连接更稳**：短暂断网、限流或页面异常不会再把直播误判为结束；恢复后继续使用同一场记录。
- **使用说明**：新增三语内置指南，降低首次使用门槛。

## 安装与开始

1. 下载 `LiveMemory-v0.13.2-rc.0-windows-x64.zip`。
2. 用 `SHA256SUMS.txt` 校验文件（见下方「校验下载」）。
3. 解压到任意可写目录（不需要安装程序）。
4. 双击 `LiveMemory.exe`。Windows 会显示 **UAC 管理员权限确认**；选择「是」后启动，选择「否」则取消启动。
5. 控制台会自动打开系统默认浏览器中的本地控制台；如果没有打开，请重新运行 `LiveMemory.exe`，不要手动打开旧地址。
6. 首次使用建议先到「设置」选择语言与主题，然后创建一次完整备份。
7. 要使用 AI：在「设置 → AI Provider」添加你的 Provider、模型和 API Key，先运行能力测试；随后在「AI 分析」选择场次开始。
8. 数据默认保存在 `%LOCALAPPDATA%\LiveMemory\`。

> 升级时替换旧的 `LiveMemory.exe` 即可，数据目录保持不变。升级前建议创建一次完整备份。

## 重要说明

- **管理员权限**：Windows 启动 `LiveMemory.exe` 时会申请管理员权限（标准 UAC）。程序不会绕过或关闭 UAC；拒绝后由 Windows 取消启动。你不需要右键选择“以管理员身份运行”。
- **自备 API Key**：AI 分析需要你自行在对应 Provider 官网创建并填写 API Key。没有 Key 时，直播记录、历史与本地功能仍可正常使用。
- **第三方费用**：AI 分析会产生第三方 API 费用，由 Provider 直接向你收取。程序显示的是按 Token 与单价计算的**估算值**，不是官方账单，请以 Provider 后台为准。
- **AI 准确性**：AI 生成的单场分析与长期画像可能存在遗漏、过度概括或误读，尤其是玩笑、反讽和临时状态。长期画像是整理结果，不是事实裁决；请展开原始证据核对。
- **Provider 验证范围**：**DeepSeek 已完成真实付费路径测试；其他 Provider 仅完成代码实现与 Mock/本地测试，尚未逐一进行真实付费验收。** 不同 Provider 的行为可能存在差异，遇到问题请先运行能力测试。
- **预发布性质**：本版本是 **RC0 预发布版本**，不是最终稳定版。功能、界面与行为仍可能调整；建议先小范围使用并保留备份。
- **管理员权限启动验收**：构建与自动化已确认 EXE 的 Manifest 为 `requireAdministrator`；真实 Windows 桌面上的 UAC 点击仍需在目标设备上做最终人工确认，自动化不能代替。

## 已知限制

- 仅支持直播，不抓取普通视频、视频评论、字幕或历史回放。
- YouTube 使用公开网页聊天路径，不是 YouTube 官方稳定 API，可能因页面改版或平台策略变化失效；程序不绕过登录、验证码、年龄墙或地区限制。
- Bilibili 未登录时，平台可能对昵称打码并把 UID 置为 0，这类消息无法归属到稳定观众；扫码登录可提高识别率，但历史打码消息不会被猜测回填。
- AI 长期画像可能不完整、过时或与事实不符；程序不会强制你审核，但也不会把 AI 输出当作事实。
- 备份未加密；不支持两台电脑的数据合并；不支持从更高版本降级。
- 本版本未使用代码签名证书，Windows SmartScreen 可能显示“未知发布者”；请用 SHA-256 校验下载文件。
- 未在干净 Windows 环境、所有杀毒软件组合或所有 Windows 版本上完成完整人工验收。

## English summary

**LiveMemory v0.13.2 RC0 (pre-release, Windows 10/11 x64)** is a local-first app for recording Bilibili and YouTube livestreams (chat, gifts, Super Chats, memberships), analysing single sessions with your own AI provider, and building long-term viewer memory across streams. Everything runs on your PC; there is no developer server and no account.

Highlights: multi-stream recording with per-stream state; viewer profiles keyed by stable platform IDs; AI reports and long-term profiles with evidence, certainty and version history; bounded retry, per-batch saving and Resume; provider-reported token usage with estimated cost; one-file `.livememory` backup, restore and migration; Simplified Chinese, Japanese and English UI with a built-in user guide.

Important:

- **Windows shows a standard UAC administrator prompt on launch.** The app never bypasses UAC; declining cancels the launch. Right-clicking “Run as administrator” is not required.
- **You must configure your own AI provider API key.** Live recording works without one.
- **AI analysis may incur third-party API charges**, billed by your provider. Cost shown by the app is an estimate, not an invoice.
- **AI long-term profiles can be incomplete or inaccurate.** Expand the original evidence and judge accordingly.
- **DeepSeek has been tested with a real paid run; other providers have only code-level and Mock/local testing**, not individual real paid acceptance.
- **This is an RC0 pre-release**, not a final stable release. Keep backups and expect changes.
- Real UAC interaction on a physical Windows desktop remains a final manual check; automation verifies the manifest and the packaged app.

Package: `LiveMemory-v0.13.2-rc.0-windows-x64.zip` — includes `LiveMemory.exe`, `README.md`, `LICENSE`, `RELEASE_NOTES.md` and `SHA256SUMS.txt`.
