# LiveMemory v0.19.4 — Flexible Memory Updates & Report Translation Fixes

Released **2026-11-24** for **Windows 10/11 x64**. Database schema **16**, no migration required. This release includes the fixes developed in the local v0.19.2–v0.19.4 patches.

## English

### What changed

- **Analyze older broadcasts after newer ones.** Long-term viewer memory supports out-of-order analysis and historical backfill. Observed time, evidence strength and historical states guide merging; repeated evidence does not increase confidence, and older information does not blindly replace a reliable current state.
- **Translate saved reports independently.** Translation only sends saved report text and paragraph identifiers. It does not read raw chat or current long-term profiles, rerun analysis or update memory. A memory update failure does not block an already saved report.
- **Fix translations that never finished.** Shared text could already have a valid translation but still appear missing because cache lookup used the broadcast that first saved it. Lookup now follows the complete cache identity. Existing valid translations remain usable without another API call.
- **Preserve progress and avoid repeated charges.** Retries include failed and missing fields, keep successful translations, process the final batch and recover after restart. Output budgets include JSON overhead; complete entries from a truncated response are retained, while protocol failures stop further requests. Provider-compatible output hints and lightweight `id`/`text` mapping remain in place.
- **Clearer errors in all ten interface languages.** Truncation, empty final answers, mismatched IDs and storage failures are distinguished. Diagnostics exclude response text and credentials. The SQLite parameter error that previously hid the original failure is also fixed.

### Upgrade

Download **LiveMemory.exe**, quit the old version and replace it. No Python, Node.js or database installation is needed. Your data directory, original reports, chat, evidence, statistics, API settings and valid translation caches are preserved. Schema remains **16** and translation cache version remains **v1**. Creating a full backup before upgrading is recommended.

Open the saved report and select the target language. Valid cached translations load without a new request; only genuinely missing or failed text requires a paid retry. There is no automatic reanalysis or translation of all historical reports.

### Verification and limits

- Automated regression: **1,348 passed / 0 failed / 2 skipped**; the skipped tests are opt-in real Credential Manager tests.
- Packaged EXE: **89/89 checks**, including shared-cache reuse, complete report translation, actual EXE restart and reopening without additional requests. These checks use a local simulated provider and an `asInvoker` functional copy; the distributed EXE's manifest is verified as **requireAdministrator**.
- Real **DeepSeek deepseek-flash**: a small synthetic Japanese report completed across multiple batches; reopening the database and filling its missing final field completed correctly; reopening again sent no extra request. An affected existing report was also verified read-only against its complete valid cache. These are not claims of paid testing for every provider or large-report scenario.
- Manual double-click UAC approval/denial, clean Windows accounts, SmartScreen behavior, browser auto-open and Ctrl+C exit remain **not manually revalidated** for this release. The EXE is **unsigned** and Windows may show an unknown-publisher warning. Standard UAC confirmation is expected; do not disable UAC.
- Other providers have implementation and simulated regression coverage, but were not individually retested with paid requests.

## 简体中文

- **报告翻译独立运行**：只翻译已保存报告文本，不读取原始弹幕或实时长期画像，不重新分析、不更新记忆。长期画像更新失败不阻碍已保存报告的翻译。

- **保留有效结果并准确报错**：合理增加输出预算，兼容轻量 JSON 格式，截断时保留完整段落；系统性协议错误停止后续请求。十语错误分类与脱敏诊断同步完善，包含此前 SQLite 参数次生错误修复。

**升级**：退出旧版后替换 `LiveMemory.exe`，不需要重装环境或清空数据。数据库仍为 Schema 16、翻译缓存仍为 v1；原报告、弹幕、证据、统计、画像及 API 设置保留。建议先创建完整备份。打开报告并选择目标语言即可读取有效缓存；真正缺失或失败的文本才需付费补译，不会自动重跑全部历史。

**验收边界**：全量 1,348 通过、0 失败、2 跳过；EXE 89/89（本地模拟 Provider）。真实 DeepSeek 已验证小合成报告从空缓存到全部完成、重开补齐及再次打开零请求；受影响报告的完整有效缓存通过只读核对。未宣称所有 Provider 或大报告均已真实付费验收。人工 UAC、干净 Windows、SmartScreen、浏览器自动打开与 Ctrl+C 尚未重新人工验收；EXE 未签名，启动时有标准 UAC 确认。

## 日本語

- **時系列に依存しない分析**：新しい配信を分析した後でも、過去の配信を追加できます。観測時刻と証拠の強さに基づき履歴を保持し、同じ証拠で確信度を上げません。
- **保存済みレポートの翻訳を独立化**：保存済み文章のみを送り、生チャットや現在の長期プロフィールの読み込み、再分析、記憶更新は行いません。
- **翻訳済みなのに完了しない問題を修正**：別の配信で保存された有効なキャッシュを正しいキーで再利用します。失敗・未完了部分のみを再試行し、最後のバッチや再起動後の処理も確認しました。
- 出力上限、途中で切れた応答の部分保存、エラー分類と十言語の診断表示も改善しました。

旧版を終了して `LiveMemory.exe` を置き換えてください。Schema 16・キャッシュ v1 のままで、元のレポート、チャット、証拠、統計、プロフィール、API 設定を維持します。更新前の完全バックアップを推奨します。有効な翻訳は追加 API 呼び出しなしで表示され、不足分だけが課金対象です。
