# LiveMemory v0.18.0 — OpenCode AI Provider

状态：**正式发布**。版本 `0.18.0`，数据库 Schema **16**（无迁移）。
本版新增 **OpenCode** 作为可选择的 AI 服务商；直播采集平台、金额、身份、去重与保留策略未改。

## 概要

- **新增 OpenCode AI Provider**：在「设置 → AI API 配置」中可以直接选择 OpenCode，
  不再需要把 OpenCode 当作自定义 OpenAI-compatible 端点填写。
- OpenCode 复用 LiveMemory 现有的 **OpenAI Chat Completions** 请求链路，因此单场分析、
  长期画像、分批处理、断点恢复、报告翻译、Token 统计和费用估算全部沿用现有能力。
- **没有真实 OpenCode API Key**：本版完成了官方协议核实、模型列表读取与自动化/模拟验收，
  **没有发出真实付费推理请求**。真实模型输出、429/5xx、账单与 `usage.cost` 仍待验收。
- 其他 Provider（OpenAI、Anthropic、DeepSeek、MiniMax、阿里云百炼、OpenRouter、
  自定义 OpenAI-compatible）的行为未改。

## 如何配置 OpenCode

1. 打开 **设置 → AI API 配置**，点击「添加配置」。
2. **Provider** 选择 **OpenCode**。
3. **Region / 平台**选择：
   - **Pay-as-you-go**（按余额付费，默认）；
   - **Go subscription**（OpenCode Go 订阅）。
   两者使用不同的官方 Base URL，必须与你的套餐一致。
4. 填写 OpenCode Console 创建的 API Key（形如 `oc_sk_…`）。
5. 点击「从官方 API 加载模型」，选择模型；也可以手动填写 **Model ID**。
6. 价格字段可选：填写后显示估算费用；不填写也能正常分析，只统计 Token。
7. 点击「检测能力」，通过后即可在「AI 分析」中使用。

LiveMemory 会自动发送 OpenCode 要求的客户端标识与 `x-opencode-session`。同一个分析任务的
分批、重试、暂停/重启/恢复会复用同一个会话标识，不同任务彼此隔离。

## 其他真实变化

- 十种界面语言的 Provider 列表与使用说明加入 OpenCode；语言键数不变，无新增文案键。
- 补充 Provider 兼容性、AI 契约、状态、路线图、测试计划与发布文档。
- 修正一个与 OpenCode 无关的旧测试夹具：30 天保留用例不再依赖运行当天的真实时间。
  **这不是产品行为变化。**

## 已知限制与注意事项

- **没有真实 OpenCode API Key**：真实推理、真实 429/5xx、真实模型输出、真实账单与
  `usage.cost` 均未验收；不得把自动化结果当作真实 Provider 验收。
- **OpenCode Go 未通过真实验收**。官方将 Go 定位为面向编码代理的服务并监测滥用流量；
  LiveMemory 按要求发送自身 User-Agent 与会话 ID，不伪装编码代理。若平台限制此类流量，
  请求会如实失败。
- OpenCode 免费层模型对第三方客户端返回 403；模型列表中的 `$0` 价格不等于 LiveMemory 可用。
- 本版未声明 `response_format: json_schema`，结构化输出仍使用「提示词 Schema + 本地校验」，
  与 DeepSeek 等 Provider 的既有路径一致。
- 部分模型（如 Claude 系列）元数据标注不支持 `temperature`；请求仍按既有形状发送，
  Console 翻译层是否丢弃该参数未验证。
- **通过自定义 OpenAI-compatible 配置 OpenCode 不会发送 OpenCode 专用会话头**；
  请使用本版内置的 OpenCode Provider，尤其是 Go 套餐。
- 切换 Provider / Region 时，出于安全设计必须重新输入 API Key；这不是配置丢失。
- 手动删除 `%LOCALAPPDATA%\LiveMemory` 下的配置文件可能被 Windows 权限或占用阻止；
  该反馈尚未复现根因，将留待后续专项调查。
- 真实双击 UAC（同意/拒绝）、干净 Windows 账户、Windows 原生文件对话框与 Ctrl+C
  仍未人工验证；EXE 未签名，SmartScreen 可能提示未知发布者。

## 升级说明

- 替换 `LiveMemory.exe` 即可；数据目录保持不变，Schema 仍 16，无需迁移。
- 现有直播数据、设置、AI 配置、任务与长期画像不受影响。
- 升级前建议在「设置 → 备份与恢复」创建一次完整备份。
