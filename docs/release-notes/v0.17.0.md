# LiveMemory v0.17.0 — 快手 H5 预览接入（采集默认禁用）

状态：**候选 / 未发布**。版本 `0.17.0`，Schema **16**（无迁移）。
本版**不包含真实 H5 采集的正式启用**；未取得快手书面许可前不得发布为“已支持快手”。

## 概要

- 新增**第七个平台页签「快手」**，但定位是**预览**：链接解析、H5 comment 适配器、
  SQLite 存储、单场 AI 分析、长期画像（会话内）、自动监控、异常恢复、十语 UI 与候选 EXE
  均已集成。
- **实时 H5 网络采集默认关闭**。默认构建中 `/api/kuaishou/connect` 在任何网络请求前
  返回 `KUAISHOU_AUTHORIZATION_REQUIRED`；`/api/kuaishou/room` 只做本地解析。
- 界面对所有语言展示明确告知：

  > 快手平台对未经授权的自动数据采集存在限制。LiveMemory 并非快手官方产品。使用者应遵守快手平台协议，并确保拥有必要的数据访问权限。第三方接口可能随时变更或停止服务。

- 六个已发布平台（Bilibili / YouTube / Twitch / 抖音 / TikTok / Kick）的协议、
  金额、身份、去重、保留策略与数据库 Schema 未改。

## 新增

### 平台与采集

- `src/platforms/kuaishou/`：`link`、`policy`、`http`、`transport`、`messages`、`status`、
  `adapter`、`service`；零运行时依赖。
- 只接受 `https://live.kuaishou.com/u/<eid>`、`https://livev.m.chenzhongtech.com/fw/live/<eid>`
  与裸 eid；拒绝个人主页、短视频、回放和其他平台。
- 只映射 `comment`：原文、昵称、数字 `userId`、毫秒时间；**无消息 ID**（`external_id=NULL`）。
- 去重：适配器 `userId + time + content` 指纹 + `UNIQUE(session_id, dedupe_key)`。
- 身份：`viewer_uid=h5:<rawUserId>@<localSessionId>`，**跨场不合并**；昵称不作身份。
- 礼物、点赞、进入、关注：不解析、不写入、不显示为支持（`NOT-OBSERVED`）。
- 30 天保留：清理原文与过期昵称，保留计数、会话内 ID 与分析结果。

### 自动监控与状态

- `MONITOR_PLATFORMS` 增加 `kuaishou`；基础间隔 120 秒、抖动 90–180 秒、错误退避到 30 分钟。
- 目标键 `eid`；场次循环键 `kuaishou:<eid>:<liveStreamId>`。
- 结束信号：H5 feed `601/671` 权威；房间页连续 2 次 `offline`；`rate_limited`/`unknown` 不结束；
  `home/list` 推荐列表缺席永远不判下播。
- 网络/超时/限流退避重试；风控/拒绝/房间不存在如实失败；新 `liveStreamId` 结束旧场。
- 授权关闭时后端拒绝创建监控目标且不发起请求；UI 不显示监控开关。

### UI 与语言

- 直播页第七个页签与完整快手面板：告知、授权状态、链接解析、房间状态、身份/消息 ID/
  礼物限制说明、30 天保留、活动记录、capture details。
- 十份字典各 **2,351** 键（新增 47 键）；键集、占位符、空值、英文残留门禁全部通过。
- 禁用状态仍可解析链接，但开始按钮禁用并显示原因；不提供任何“绕过授权”入口。

### 测试与构建

- 新增 `tests/unit/kuaishou-*.test.mjs`（链接、消息、状态、门禁、传输、适配器、UI）
  与 `tests/integration/kuaishou-*.test.mjs`（服务/路由/存储/AI 包/监控）。
- `scripts/build-windows.mjs` 必需模块与 EXE 标记加入全部 Kuaishou 模块与 detector。

## 未验证 / 已知限制

- **无快手书面许可**：官方条款禁止未经授权的自动采集，H5 `robots.txt` 为 `Disallow: /`。
- 未在许可下做真实 H5 长测、真实下播→再开播、真实多房间并发。
- 跨场/跨日 `userId` 稳定性未证明；当前会话内身份，跨场画像不聚合。
- H5 无消息 ID、无续传游标；重连期间可能漏消息，同一用户同毫秒同内容可能被去重。
- 礼物/点赞 `NOT-OBSERVED`；不声称支持。
- 真实双击 UAC、干净 Windows 账户未人工验证；EXE 未签名，SmartScreen 可能提示。
- 非官方 H5 接口可能随时变更或停止；不作为官方 API、授权或“合规”描述。

## 升级说明

- Schema 仍 16；无需迁移。
- 现有六平台数据、设置、AI 任务与长期画像不受影响。
- 快手只在用户主动打开第七个页签时生效；默认不产生网络请求。
- 内部许可测试（不随正式发布提供）：同时设置
  `LIVEMEMORY_KUAISHOU_H5_OPT_IN=1` 与 `LIVEMEMORY_KUAISHOU_AUTHORIZATION_ACK=<引用>`；
  该开关只表示运营者声明已获许可，不能取得授权。
