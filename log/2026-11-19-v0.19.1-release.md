# 2026-11-19 v0.19.1 正式发布：Windows Credential Storage Fix

## 1. 发布范围

本轮把 AI Provider API Key 从自维护 AES JSON 凭据库迁移到 Windows Credential Manager，
修复部分 Windows 用户保存时遇到的 `AI_PROVIDER_CREDENTIAL_PERMISSION` 凭据文件权限故障，
并正式发布为 **v0.19.1**。

未改直播平台协议、数据库 Schema（仍 16）、金额/身份/去重、任务语言快照、提示词、
UAC/Manifest。快手仍为预览、采集禁用。
