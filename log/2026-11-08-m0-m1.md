## 4. 遇到的问题与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 工作区写入被拒绝 | Windows ACL 缺少 WRITE_OWNER | 运行 DSH ACL 修复脚本，补当前用户完全控制 |
| git 无法访问 GitHub | schannel 凭证错误 | `git -c http.sslBackend=openssl clone` |
| 事件写入 FOREIGN KEY 失败 | 先插事件后建观众 | `ensureViewer()` 在插入事件前执行；聚合仍只在插入成功后更新 |
| 直播页显示“出现问题” | 图表把 bucket 对象传给时间格式化函数 | 传 `bucket.startAt`；格式化函数增加非法日期保护 |
| 最近动态为空 | 初次截图过早 + 页面缓存 | 静态资源改 `no-cache`；截图等待加长 |
| 桌面出现汉堡菜单 | `.icon-button` 覆盖了 `.menu-button{display:none}` | 在 components.css 中重排规则并加移动端覆盖 |
| 分析包 manifest 自校验和过期 | 先算校验和再改 manifest | manifest 排除自身，仅校验 5 个内容文件 |
| EXE 构建 tar EPERM | 沙箱禁止管道 stdio | `execFileSync(..., {stdio:'inherit'})` |
| EXE 默认数据目录失败 | 沙箱禁止写 `%LOCALAPPDATA%` | bootstrap 增加临时目录回退；真实用户环境不受影响 |
| 测试运行 EPERM | `node --test` 为每个文件 spawn | `--test-isolation=none` 单进程运行 |
| 测试断言与实际不符 | 分桶步长、内容清理行数、current 返回结构 | 修正断言，不修改业务逻辑 |
