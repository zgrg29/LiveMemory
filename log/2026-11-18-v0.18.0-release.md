## 2. OpenCode 发布验收

- Provider 可在设置中选择；两个 Region（Pay-as-you-go / Go）来自目录，复用既有 UI。
- API Key 只进本地加密凭据库；配置 JSON、日志、结果与 EXE 均无真实 Key。
- 模型列表真实读取官方 `/inference/v1/models`（87 个 chat 模型，2026-11-18）。
- Go `x-opencode-session`：真实请求缺少该头返回 400 `MissingSessionID`；带任意非空值后
  进入鉴权（401）。LiveMemory 按 `ai_jobs.id` 派生稳定 `ses_<hash>`，批次、重试、
  暂停/重启/Resume 复用；并行任务隔离。
- 单场分析、长期画像、分批恢复、报告翻译复用现有链路；新增 12 unit + 3 integration 通过。
- 其他 Provider 未改；全量 1,241 通过。
- 十语 i18n：10 × 2,351 键，无新增键；仅 Provider 列表/使用说明改值。
- 真实 OpenCode 推理：**未执行（无 Key）**；Go 未真实验收。

## 3. 用户反馈核查（不纳入专项修复）

| 手动删除 AppData 配置文件权限问题 | 未在本轮复现为发布阻断；属于 Windows 文件权限/占用，留待专项调查。 |
