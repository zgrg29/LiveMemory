# 2026-11-11 v0.13.1 移除匿名/手动 AI，重写付费调度

## 目标

- 调查付费 API 是否复用了匿名 OVH 的 2 请求/分钟限速。
- 删除匿名免费 AI 与手动提示词/JSON 入口。
- 保留自备 API Key 的自动分析、多 Provider、验证/导入/报告。
- 提高大批量直播的调度效率，同时保留 429/Retry-After、并发/预算/取消/重试与数据安全。

## 审计结论

- 付费路径 `src/ai/api/runner.mjs` **没有**使用 `SlidingWindowLimiter`。
- 2 RPM 只在 `src/ai/auto/config.mjs:93` + `src/ai/auto/runner.mjs:121-128` 的匿名路径。
- 旧付费路径真实问题：完全串行、30 批上限、固定 1.2/2.4s 重试、忽略 `Retry-After`、每批重扫全部观众、每次请求 DNS、`listPackages` 50 条上限。
- 详见 `docs/AI_SCHEDULER_AUDIT.md`。

## 实施

- 删除 `src/ai/auto/` 与 `/api/ai/auto/*`；删除匿名 Provider、免费状态、UI 入口。
- 删除手动写路由/UI：jobs POST、aggregate、packages POST/download、instructions、import preview/import。
- 新增 `src/ai/runtime/json.mjs`、`state.mjs`、`scheduler.mjs`。
- `AnalysisRunner`：必须 configId；按 configId 调度；有界并发；429+Retry-After；指数退避+抖动；请求统计；记忆顺序 gate；1,000 观众批次上限。
- 修复：`getJobPackage()` 精确查询；每批只更新本批观众；DNS 安全缓存 5 分钟。
- UI：五步单入口、费用/预算、请求统计、暂停/取消/继续、错误原因。
- i18n：新增 `ai.center.*`，删除 `ai.auto` 与手动/匿名方法。
