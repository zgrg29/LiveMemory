## 3. 实现

### 3.1 平台模块

- `link.mjs`：频道链接/账号规范化；拒绝视频、剪辑、目录、搜索、外站。
- `irc.mjs`：IRCv3 标签与转义、多行帧、`emotes` 范围、`badges`、`/me` ACTION；纯函数。
- `mapper.mjs`：PRIVMSG/Cheer/USERNOTICE → canonical draft；显式忽略系统通知；证据等级。
- `client.mjs`：公开 GQL 只读元数据（channel id / displayName / title / stream.id / viewers / startedAt）；
  使用 Twitch 公开网页 client id，无登录、无 token、无 cookie、无第三方付费服务。
- `adapter.mjs`：匿名 IRC、CAP tags/commands、JOIN、ROOMSTATE 校验、PING/PONG、90 秒看门狗、
  1→30 秒退避、15 次后 5 分钟低速探测、连接内 10,000 消息 ID 去重、两次离线确认、stream id 变化结束旧场、
  用户停止不再重连。
- `service.mjs`：check/connect/connectDetected/disconnect/status/retention；重复房间；稳定 broadcaster id。
- `monitoring/detectors/twitch.mjs`：解析目标、直播/离线观察、`stream.id` 周期键、错误分类。

### 3.2 统一体系接入

- 所有事件仍只经 `src/platforms/shared/ingest.mjs`；没有新增写入路径。
- `SessionManager.startPlatform` 复用；`platformRoomId = channelId`，`broadcasterUid = channelId`。
- `MonitoringManager` 增加 `twitch` detector、策略（120 秒基准、90–180 秒抖动、pacer 1.5 秒）、
  `#startPlatformSession` 分支、周期键与显示名。
- 路由：`/api/twitch/status|channel|connect|disconnect|retention/apply`。
- UI：直播页 Twitch 来源 Tab、频道检查、自动监听、三语错误/能力说明、保留按钮；
  `popular` 金额显示改用 `amount_display`，避免 Bits 显示为 0.00；历史筛选增加 Twitch。
- retention：平台化昵称清理；Twitch-only 30 天；审计键 `retention.lastRun.twitch`，不覆盖 YouTube。

### 3.3 数据库/AI

- **未改 schema（16）**：现有 canonical event 足够表达聊天、会员、赠订、Bits；不新增表/列。
- 金额：Bits/Tier/月数没有本币金额，`amount_minor=null`、`currency=null`、`value_kind=unknown`；
  Bits 数量写 `gift_quantity`，展示文本写 `amount_display`。
- AI：复用现有分析包/报告/长期画像；Twitch 事件通过 `viewer_id=twitch:<id>` 进入现有读模型。
  未新建 Twitch 专用 AI 系统，未改 Provider/调度/提示词。

## 6. 遇到的问题与处理

1. **`git`/`node` 不在 PATH**：使用 GitHub Desktop 内置 Git 与 DSH 自带 Node 24.21.0。
2. **`.git` ACL 拒绝**：创建分支/提交需一次性 full access；提交需 `--allow-empty`（环境已知现象）。
3. **ROOMSTATE 测试误把 `room-id` 放在 trailing**：修正测试为真实 tags 形式；
   真实网络验证确认 `@room-id=... ROOMSTATE #xqc` 可用。
4. **Bits 未知金额 UI 显示 0.00**：改为优先 `amount_display`，无金额时显示未知，不伪造法币 0。
5. **retention `lastRun` 被 Twitch 覆盖**：改为平台化审计键，YouTube 保持 `retention.lastRun`。
6. **Bilibili 5050 未开播**：不是回归；改用房间 6 完成真实回归。
7. **EXE 自动化无法点击 UAC**：沿用项目既定方案，正式 EXE 断言 Manifest，功能场景使用同一二进制
   asInvoker 测试副本；真实 UAC 双击列为人工验收。
